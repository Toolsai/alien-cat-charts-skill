# Orbital Play

深靛色是一片安靜的閱讀空間。奶油白提供可停留的表面，薄荷綠與明黃構成探索的信號。每一種顏色都有工作，精心校準的比例讓歡樂不搶走內容的注意力。

大小的節奏由少量清晰的層次建立：標題先被讀見，圖解承接視線，角色最後邀請互動。這種有分寸的留白與尺度，需要細緻打磨；真正的工藝藏在對齊、間距與邊界之間。

角色來自同一套原創素材，輪廓厚實、表情開放。畫面把它們當作學習的旅伴，以真實產品畫面作為中心證據，避免用裝飾取代體驗。每一個裁切都保持圖解的完整意思。

軌道與點線是低調的主題線索：閱讀像一站接一站的小旅程，而不是一次吞下整篇文章。封面與預覽以經過反覆檢視的排版連成同一個視覺語言，文字只留下必要的引導。
